# 📝 Task Manager App

Aplicação de gerenciamento de tarefas desenvolvida com React.

## 🚀 Funcionalidades

* Adicionar tarefas
* Remover tarefas
* Marcar como concluída
* Filtrar por status
* Buscar tarefas

## 🛠️ Tecnologias

* React
* JavaScript
* CSS
* Vite

## 📦 Como rodar

```bash
npm install
npm run dev
```
