# 📝 Task Manager App

Aplicação web para gerenciamento de tarefas, com foco em produtividade e organização do dia a dia.

## 🚀 Funcionalidades

* Adicionar tarefas
* Remover tarefas
* Marcar como concluída
* Filtrar por status
* Buscar tarefas

## 🛠️ Tecnologias

* React
* JavaScript
* CSS
* Vite

## 📦 Como rodar

```bash
npm install
npm run dev
```
